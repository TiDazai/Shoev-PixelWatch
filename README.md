[Русский](README.md) · [English](README.en.md)

Нативная утилита для macOS от **SHOEV SYSTEMS / SHOEV PRODUCTS**. Выберите область экрана или окно приложения, задайте правило и получите уведомление об изменении. Бесплатно, лицензия MIT. Без аккаунтов, подписок, облака и телеметрии.

Интерфейс использует фирменные цвета SHOEV: **платину, золото и серебро**. Полностью поддерживаются **русский и английский языки**. Язык меняется сразу в открытых окнах и меню; новые установки по умолчанию используют русский.

## Скачать и запустить

Готовые сборки доступны в [GitHub Releases](https://github.com/TiDazai/Shoev-PixelWatch/releases). Минимальная система — **macOS 26.0**. Приложение собирается для **Apple Silicon и Intel**.

1. Скачайте DMG, откройте его и перенесите SHOEV PixelWatch в «Программы».
2. Запустите приложение. Оно работает в строке меню.
3. Разрешите запись экрана и уведомления, когда macOS запросит доступ.
4. Нажмите **Новое наблюдение**, выберите источник и правило.

Текущие сборки подписаны локальной ad-hoc подписью. Developer ID и нотарификация Apple ещё не выполнены; подготовленные команды для публичной подписи описаны в [инструкции Release](docs/RELEASE.md).

## Что умеет PixelWatch

| Режим | Пример |
| --- | --- |
| Любое визуальное изменение | Изменилось изображение, график или статус |
| Появление текста | В области появилось `In stock` |
| Исчезновение текста | `Processing` сменилось на `Completed` |
| Изменение текста | `Pending` → `Approved` |
| Изменение после стабильного состояния | Область успокоилась после анимации, затем изменилась |

- Системный выбор источника ScreenCaptureKit и выделение области мышью.
- Поддержка Retina и нескольких мониторов, включая отрицательные координаты.
- Локальное распознавание русского и английского текста через Vision.
- Подтверждения, чувствительность, интервал, пауза между уведомлениями, однократное и постоянное наблюдение.
- Пауза и возобновление, работа при закрытой панели, сохранённые правила и история событий.
- Системные уведомления со звуком и открытием нужного наблюдения.
- Светлая и тёмная темы, запуск при входе, настройки конфиденциальности и удаление локальных данных.
- Ограниченный буфер кадров и повторное использование потоков; изображения не сохраняются на диск.

## Разрешения и ограничения

Откройте **Настройки → Конфиденциальность → Запросить разрешение**. В macOS разрешите PixelWatch доступ к записи экрана. После изменения разрешения система может попросить перезапустить приложение. Системный выбор источника может дать доступ только на текущий сеанс; после перезапуска сохранённым наблюдениям нужен постоянный доступ или повторный выбор источника.

Разрешение на уведомления не влияет на обнаружение событий: при отказе они остаются в истории. Для баннеров и звука проверьте также настройки уведомлений macOS и режим фокусирования.

**Область экрана** отслеживает видимые пиксели. Перекрывающее окно меняет то, что видит PixelWatch. При смене разрешения монитора область нужно выбрать заново. **Окно приложения** следует за выбранным окном при перемещении; свёрнутое, закрытое или защищённое окно может быть недоступно. После перезапуска приложения-источника выберите его новое окно.

«Исчезновение текста» сначала подтверждает наличие текста. Пустой или неуверенный результат OCR не считается исчезновением. После потери источника, сна или паузы базовое состояние устанавливается заново. Явная остановка доступа через системные элементы macOS приостанавливает наблюдение до команды пользователя.

Все данные анализируются локально. Сохраняются только настройки, правила и текст событий в `~/Library/Application Support/SHOEV PixelWatch/`. Подробнее — [PRIVACY.md](PRIVACY.md).

## Сборка из исходников

Откройте `PixelWatch.xcodeproj`, выберите схему **PixelWatch** и нажмите Run. Сторонние зависимости и генераторы проекта не нужны. Для сборки нужен Xcode 26 или новее с SDK macOS 26+. Проверенное окружение: Xcode 26.3, Swift 6.2.4, macOS SDK 26.2.

```sh
git clone https://github.com/TiDazai/Shoev-PixelWatch.git
cd Shoev-PixelWatch
xcodebuild -project PixelWatch.xcodeproj -scheme PixelWatch \
  -configuration Debug -derivedDataPath build build
open "build/Build/Products/Debug/SHOEV PixelWatch.app"
```

Release и DMG:

```sh
./scripts/build-release.sh
./scripts/create-dmg.sh
```

Результат: `dist/SHOEV PixelWatch.app` и `dist/SHOEV-PixelWatch-0.1.1.dmg`.

## Проверки

```sh
python3 scripts/check-localization.py
swift test
xcodebuild -project PixelWatch.xcodeproj -scheme PixelWatch \
  -configuration Debug -derivedDataPath build \
  -destination 'platform=macOS,arch=arm64' test
open Demo/index.html
```

На Intel используйте `arch=x86_64`. Автоматические тесты не требуют доступа к записи экрана: используются локально созданные изображения и mock-провайдеры. Проверяются правила, OCR, переходы состояний, хранение, обработка кадров и локализации, включая сохранение переводов при повторной сборке.

Полная ручная проверка захвата и доставки уведомлений требует разрешений macOS. Результаты реально выполненных проверок и оставшиеся ограничения приведены в [VALIDATION.md](docs/VALIDATION.md). [Шесть сценариев приёмки](docs/MANUAL-TESTING.md) используют локальную тестовую страницу.
