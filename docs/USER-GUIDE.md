# Руководство пользователя

## Первое наблюдение

1. Запустите PixelWatch и пройдите вводные шаги. Разрешите запись экрана для постоянной работы сохранённых наблюдений.
2. Нажмите значок в строке меню → **Новое наблюдение**.
3. Выберите **Область экрана** или **Окно приложения**. В системном диалоге укажите один монитор или одно окно. На macOS 15.0–15.1 используется список доступных источников с разрешением на запись экрана.
4. Для области экрана выделите прямоугольник мышью. Перетащите его изнутри, чтобы переместить; начните выделение снаружи, чтобы изменить размеры. **Enter** подтверждает выбор, **Escape** отменяет.
5. Введите название, выберите правило и нажмите **Начать наблюдение**. При необходимости разрешите уведомления. При отказе события всё равно сохраняются в истории.

## Правила

| Режим | Для чего подходит | Что происходит сначала |
| --- | --- | --- |
| Любое визуальное изменение | Изменение картинки, графика, области статуса | Первый доступный кадр становится исходным |
| Появление текста | Появление «В наличии» или `Completed` | Текст должен совпасть в нескольких последовательных проверках |
| Исчезновение текста | Смена `Processing` на `Completed` | Сначала подтверждается наличие указанного текста |
| Изменение текста | `Pending` → `Approved` или «Ожидает» → «Одобрено» | Подтверждается стабильное исходное значение |
| Изменение после стабильного состояния | Загрузчик успокоился, затем статус изменился | Область должна быть стабильной заданное время |

Чувствительность влияет на размер визуального изменения, который вызовет событие. Для шумных областей увеличьте число подтверждений или интервал. Минимум — две подтверждающие проверки. По умолчанию: интервал 2 секунды, два подтверждения, пауза между уведомлениями 30 секунд.

**Остановить после первого срабатывания** включает однократный режим. Иначе наблюдение продолжается и повторно срабатывает только после противоположного состояния или нового подтверждённого значения. Одинаковый текст не вызывает бесконечные уведомления.

**Полное совпадение распознанного текста** сравнивает весь текст выбранной области с условием. Обычный частичный поиск удобнее для строк вроде «Статус: Completed». Регистр и лишние пробелы не влияют на совпадение. Распознавание русского и английского текста выполняется локально.

Пустой результат распознавания не доказывает исчезновение текста. Используйте читаемый новый статус. После сна, потери источника или паузы базовое состояние устанавливается заново; режим исчезновения должен снова увидеть исходный текст.

## Панель наблюдений

Выберите наблюдение, чтобы увидеть предпросмотр, правило, статус, последнюю успешную проверку, статистику и историю. Доступны **Приостановить**, **Возобновить**, **Изменить**, **Удалить** и **Проверить уведомление**.

**Выбрать новый источник** сохраняет название, правило и историю существующего наблюдения. Это полезно после изменения разрешения дисплея, перезапуска приложения-источника или истечения системного разрешения.

**Приостановить все** освобождает потоки после остановки последнего наблюдения, использующего каждый поток. **Возобновить все** запускает наблюдения с новой базовой точкой, включая ранее сработавшие однократные правила. Закрытие панели не прекращает работу. **Выйти из PixelWatch** завершает приложение и захват.

## Настройки

- **Основные:** запуск при входе, запуск свёрнутым, число наблюдений в строке меню, русский/английский язык. Язык меняется сразу, без перезапуска.
- **Наблюдение:** параметры по умолчанию для новых правил.
- **Уведомления:** включение, звук, системное разрешение и проверка доставки.
- **Конфиденциальность:** доступ к записи экрана, расположение локальных данных, очистка истории и полное удаление данных.
- **О приложении:** версия, лицензия MIT, SHOEV SYSTEMS / SHOEV PRODUCTS и GitHub.

Для запуска при входе храните приложение в постоянном месте, например в «Программах». macOS может попросить включить элемент входа в системных настройках. После перемещения приложения регистрацию иногда нужно повторить.

## Источники и конфиденциальность

Область экрана отслеживает видимые пиксели фиксированного участка. Если его перекрыть другим окном, PixelWatch увидит новое содержимое. Окно приложения захватывается независимо от перекрытия, насколько это разрешено macOS; оно может стать недоступным при сворачивании, закрытии или защите содержимого.

Смена порядка мониторов не меняет локальные координаты области. Отключённый монитор может восстановиться по своему UUID. Изменение разрешения дисплея требует нового выбора области. Перезапущенное приложение-источник получает новое окно, которое нужно выбрать явно.

Ни изображения, ни звук не сохраняются и не передаются в сеть. В локальном JSON хранятся только правила, настройки и текстовая история событий. Политика хранения описана в [PRIVACY.md](../PRIVACY.md).
